SpecTalkZX 1.4.1 Triton

IRC client for the ZX Spectrum, Spectrum Next and the Spectranext cartridge.

Spectranext

In the Spectranext menu choose Load Resource URL and enter
https://ignaciomonge.github.io/spectalkzx/

The guided installer writes SpecTalkZX to cartridge storage and starts it. Afterwards start SPCTX.ZX from local storage; run the installer again to update. Configuration and bookmarks stay under /CFG.

Needs cartridge firmware 0.9-6fc153a3 or later.

Classic ZX and Spectrum Next

Download the TAP set or the NEX from the latest release.
